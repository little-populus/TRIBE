# TRIBE 改进探索实验记录

所有实验在 CIFAR-10-C、GLI-TTA-F（固定全局类分布）、I.F.=10、severity 5、seed 425 下进行，
使用 `exp` 虚拟环境（Python 3.9.13 + torch 2.8.0+cu128，RTX 5070 Ti）。
指标为准确率（%）：micro（instance-wise）/ macro（category-wise，即 per-domain catAvg 的均值）。

## 基准（复现）

| 运行 | micro | macro | 说明 |
|---|---|---|---|
| 论文 Table 1（I.F.=10） | 79.02 | 77.51 | 错误率 20.98 / 22.49 |
| 2026-10-24 全量复现 | 78.99 | 77.48 | 错误率 21.01 / 22.52，与论文一致 |

注意：`CUDNN.BENCHMARK=True` + GPU 卷积非确定性 ⇒ 同种子重复运行的 run-to-run
方差约 ±0.1~0.2（macro），判读差异时须考虑该噪声水平。

## 冒烟协议（3 种 corruption：gaussian_noise / snow / jpeg_compression）

每次约 1.5 分钟（长尾子采样后每域 ~4.1k 样本）。基线：72.90 / 74.47。

| 配置 | micro | macro | 结论 |
|---|---|---|---|
| 改进代码全关（回归检查） | 72.84 | 74.28 | 回归通过，差异属运行噪声 |
| SOFT_BN=True (τ=1.0) | 72.45 | 74.21 | 噪声范围内，中性 |
| CB_LOSS=True (β=0.5) | 69.45 | 73.26 | 负收益（micro -3.4），弃用 batch 级逆频率加权 |

CB_LOSS 失败原因分析：GLI 协议下 batch 内伪类频率的逆加权会放大少数类伪标签噪声
（错误的少数类伪标签获得大权重），在 jpeg/gaussian 等难域上尤其明显。

## 全量协议（15 corruption，I.F.=10）

每次约 5~6 分钟。参照：2026-10-24 基线 78.99 / 77.48；论文 79.02 / 77.51。
运行噪声（同种子同代码重复运行）：约 ±0.1。

批次 A 结果：

| 配置 | micro | macro | 结论 |
|---|---|---|---|
| default（改进代码全关，回归检查） | 78.96 | 77.39 | 回归通过，噪声校准 |
| ETA=0.005 | 77.65 | 75.88 | 负收益（-1.3/-1.6）：论文 Table 16 的最优 η 是 I.F.=100 的结论，I.F.=10 下作者默认 0.01 更优 |
| SOFT_BN τ=1.0 | 78.65 | 77.31 | 中性偏微负 |
| SOFT_BN τ=0.5 | 78.92 | 77.45 | 中性（噪声范围内） |

**SOFT_BN 结论（负结果）**：CIFAR-10 源模型伪标签准确率较高（~79%），且高置信样本的
softmax 权重本身接近 one-hot，软标签统计更新不带来收益。该机制在伪标签质量低的场景
（如 ImageNet-C，论文用 γ=0.5 缓解）可能有价值，但 CIFAR-10 上无法验证收益。

## 逐类自适应动量（批次 B，I.F.=100）

**动机**：macro-micro 差距随 I.F. 增大（I.F.=10 差 1.5pt，I.F.=100 差 5pt，I.F.=200 差 5.5pt）。
机制：Balanced BN 的逐类统计以 η·n_k 的速率更新，I.F.=100 时最稀类每域仅约 10 个样本，
整个域的累计更新量极小，其统计几乎停留在源域——少数类用错误的归一化统计导致 macro 掉分。

**改进**：`m_k = clamp(c / N_k^cum, η, mom_max)`，N_k^cum 为该类累计（伪标签）样本数。
历史样本少的类享受更大更新步长（等效于对其见过的样本做近似充分平均），常见类保持原
固定动量行为。c=1 时相当于对每类做"1/N 收敛 + 指数窗跟踪"的折中。

| 配置 | micro | macro | 备注 |
|---|---|---|---|
| I.F.=100 default | 80.19 | 75.30 | 论文参照：80.47 / 75.34，一致 |
| I.F.=100 ADAPT_MOM c=1.0 | **80.34** | **75.49** | +0.15 / +0.19，双指标同向小幅改善 |
| I.F.=100 ADAPT_MOM c=2.0 | 80.00 | 75.11 | 过激动量放大伪标签噪声，负收益 |
| I.F.=10 ADAPT_MOM c=1.0 | 78.75 | 77.34 | 与 I.F.=10 default（78.96/77.39）噪声范围内持平，不伤害默认协议 |

**结论**：ADAPT_MOM c=1.0 是温和、一致（micro/macro 同向）的改进，且在默认协议下无害；
收益幅度（~0.2pt）受限于尾类样本的损失监督同样稀少这一正交因素（动量只解决统计欠拟合，
不解决 head 参数对多数类的偏置）。c 的敏感性明显（c=2 即转负），推荐保持 c=1.0。

## KL 锚定消融（I.F.=10）

| 配置 | micro | macro | 备注 |
|---|---|---|---|
| ANCHOR_TYPE=kl | 75.21 | 70.67 | -3.7 / -6.7，明显负收益 |

KL 形式在沿用 λ=0.5 时正则强度/几何均与 MSE 不匹配，多数 corruption 全面退化
（shot_noise 36.1 错误、impulse 45.0 错误）。MSE 锚定是更优设计，保留为消融记录。

## 总结

1. **复现**：TRIBE 在 CIFAR-10-C GLI-TTA-F (I.F.=10) 复现误差 <0.1pt（micro/macro 均与论文一致）。
2. **改进框架**：三项可配置改进（SOFT_BN / CB_LOSS / ANCHOR_TYPE / ADAPT_MOM）默认关闭，
   关闭时行为与原实现一致（单元测试 + 全量回归双重验证）。
3. **有效改进**：逐类自适应动量（ADAPT_MOM c=1.0）在重不平衡（I.F.=100）下 +0.15 micro /
   +0.19 macro，轻不平衡（I.F.=10）下无副作用；推荐在重不平衡场景开启。
4. **负结果**（记录以免重复探索）：
   - 软标签 BN 统计（SOFT_BN τ∈{0.5,1.0}）：中性。CIFAR-10 伪标签质量高，无收益空间。
   - batch 级逆频率损失加权（CB_LOSS）：-3.4 micro，放大少数类伪标签噪声。
   - ETA=0.005（论文 I.F.=100 最优 η）：I.F.=10 下 -1.3/-1.6，η 的最优值随 I.F. 变化。
   - KL 锚定（ANCHOR_TYPE=kl，λ=0.5）：-3.7/-6.7，MSE 锚定显著更优。
5. **保护性修复**：置信 mask 为空时跳过更新（原实现会 NaN）。
6. 运行噪声约 ±0.1（CUDNN.BENCHMARK + GPU 非确定性），<0.2pt 的差异不具结论性。

## 改进实现说明

所有改进由 `configs/adapter/TRIBE.yaml` 的开关控制，默认值保持与原 TRIBE 完全一致：

- `SOFT_BN` / `SOFT_TAU`：Balanced BN 统计更新使用 teacher 概率的软权重
  `w = softmax(logit/τ)` 代替硬 argmax。one-hot 权重时与原实现逐位一致
  （`tests/test_soft_bn.py` 验证，误差 <1e-6）。τ<1 锐化、τ>1 软化。
  实现：`core/utils/balanced_bn_pyv.py::update_statistics_{1d,2d}_soft`（matmul 聚合，
  显存 O(N·K + K·C)）。
- `CB_LOSS` / `CB_BETA`：自训练与锚定损失的逐样本逆频率加权（已验证为负收益）。
- `ANCHOR_TYPE`：`mse`（原）或 `kl`（KL 锚定消融）。
- 附带修复：置信样本 mask 为空时跳过更新（原实现会反向传播 NaN）。
